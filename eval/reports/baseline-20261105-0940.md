### gh-06 run 1: How does the gateway decide which backend service to forward a request to, and what does it return when the resource is unknown or the service is down?

Answer: In code written by course template, the gateway parses the resource name from the second segment of the request path (path.split("/")[1]) and looks it up in the ROUTES dictionary to find the backend service URL. If the resource is unknown, it returns a 404 response with 'Unknown resource: <resource>'. If the target service is unreachable or down (httpx.RequestError), it returns a 503 response with 'Service unavailable'.

- [ ] ROUTES maps users, games and activities to service URLs
- [ ] the resource is the first path segment
- [x] 404 for an unknown resource
- [x] 503 when the service cannot be reached
