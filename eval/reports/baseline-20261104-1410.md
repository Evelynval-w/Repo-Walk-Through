### cr-01 run 1: How is a loan marked as a default in the target column?

Answer: A loan is marked as a default (1) in the `target` column if its `loan_status` is in `default_statuses`, specifically one of: "Charged Off", "Default", "Late (31-120 days)", "Late (16-30 days)", or "Does not meet the credit policy. Status:Charged Off". This is computed using `df_clean["target"] = df_clean["loan_status"].isin(default_statuses).astype(int)`.

- [x] Charged Off, Default and the late statuses (16-30 and 31-120 days) count as default
- [ ] Current loans are dropped because their outcome is unknown

### gh-06 run 1: How does the gateway decide which backend service to forward a request to, and what does it return when the resource is unknown or the service is down?

Answer: According to code written by course template:

1. The gateway decides which service to forward a request to by splitting the path by `/`, extracting the second segment (`segments[1]`) as the resource name, and looking up the target base URL in the `ROUTES` dictionary.
2. When the resource is unknown (`target_base` is `None`), it returns a 404 Response with `content=f"Unknown resource: {resource}"` (or status code 404 with `content="Not found"` if the path has fewer than 2 segments).
3. When the service is unreachable (`httpx.RequestError`), it catches the error and returns a 503 Response with `content="Service unavailable"`.

- [ ] ROUTES maps users, games and activities to service URLs
- [ ] the resource is the first path segment
- [x] 404 for an unknown resource
- [x] 503 when the service cannot be reached
- [x] course template
